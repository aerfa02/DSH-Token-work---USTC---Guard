# USTC API Guard v1.0.0

在 DSH 或 TokenWorks（词元工坊）中查看 USTC 模型的用量、预计费用和历史图表。

## 功能

- 今日、近3小时和近12小时用量面板，以及最小化浮条。
- Token、预计费用和历史趋势图表。
- 修复 DSH 切换官方模型后插件界面仍显示的问题。

## 安装与卸载

下载 **DSH-Token-Guard-v1.0.0.zip**，完整解压。保存工作并完全退出应用，双击 **install.bat**，选择应用、程序文件及实际使用的配置目录，完成后重启应用。无需另外安装 Node.js 或 npm。

卸载时完全退出应用，运行 **uninstall.bat**，选择相同程序和配置。已有用量记录会保留。详细说明及界面预览见压缩包内README.md；SHA256SUMS.txt可用于核对下载文件。

## 兼容范围

面向Windows 10/11，需要Windows PowerShell 5.1和可写的本地NTFS配置目录。已在本机Windows环境验证安装流程；没有覆盖所有电脑及宿主版本，macOS、Linux和Windows ARM暂未验证。
