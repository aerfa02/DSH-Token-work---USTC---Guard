USTC API Guard 使用说明

查看 USTC 模型的用量、预计费用和历史趋势。插件按实际服务地址 api.llm.ustc.edu.cn 识别请求，支持蓝白监控面板和鲸鱼娘动画。

安装面板与图表费用与预算数据与回滚常见问题素材与许可

安装与启动

DSH：使用一键安装包

  1. 取得 USTC一键安装包.zip 并解压。安装包旁的 SHA256SUMS.txt 用于核对文件完整性。
  2. 保存工作，完全退出 DSH，包括系统托盘中的进程。
  3. 双击 install.cmd，输入包含 DeepSeek Harness.exe 的安装目录，再确认当前用户的 profile 路径。
  4. 看到 SUCCESS 和安装核对结果后，重新启动 DSH，选择 USTC 地址的模型查看监控面板。

一键安装使用 Windows PowerShell 和 DSH 自带运行时，无需另装 Node.js。安装工具会备份原插件和 profile，请保存终端显示的备份路径。

从源码安装

在源码仓库根目录执行；示例中的安装目录请替换为你的实际路径。

powershell -NoProfile -ExecutionPolicy Bypass -File tools/install-local.ps1 -DshDirectory 'D:\Apps\DSH' -ProfileDirectory "$env:USERPROFILE\.dsh\profiles\desktop"

TokenWorks（词元工坊）

完全退出 TokenWorks 后，在源码仓库根目录运行：

powershell -NoProfile -ExecutionPolicy Bypass -File tools/install-tokenworks.ps1 -TokenWorksDirectory 'D:\Apps\TokenWorks'

工具默认使用当前用户 LocalAppData 下的数据目录和 desktop-017 profile。若你的 profile 不同，应在安装前按 tools/install-tokenworks.ps1 的调用方式指定正确路径。

面板与历史图表

日常监控

主面板显示今日、近 3 小时和近 12 小时费用及预算进度。拖动顶部横条移动，双击复位；最小化后保留今日和近 3 小时费用。

用量详情

详情按钮打开近 3/6/12/24 小时及日、周、月历史。切换 Token 与预计费用纵轴，筛选类型，点击柱子查看明细，翻页查看更早记录。

角色动画

鲸鱼娘支持透明背景、眨眼、视线跟随和点击自拍。最小化仍显示；隐藏页面暂停，系统减少动画时静止，加载失败回退 GIF。

连接提示

读取中、连接异常和地址识别等待会显示提示。确认选中其他平台地址后隐藏；首页没有选中会话时，检测到 USTC 路由即可显示。

TokenWorks 的认证和消息转换包装流程保持原样。插件读取内层实际服务地址；其他服务地址按原宿主行为处理。

费用与预算

  • 每百万 Token：普通输入、输出及缓存写入按 ¥2 估算，缓存命中按 ¥0.2 估算；推理不重复叠加收费。
  • 默认近 3/12/24 小时预算提醒线为 ¥30/¥70/¥100，RPM 和并发默认 20。
  • 未确认预留不计入已消费进度。缺失部分用量时显示已知费用下界；全部未知时显示待确认。

金额是本机估算，不等同平台账单。图表中的历史预计费用按相同固定单价折算。

数据、备份与回滚

记录按 Asia/Shanghai 的请求发送日期归档，周一为周起点。每日汇总长期保留，48 小时后的请求明细压缩到日汇总。旧版本已删除的更早记录无法补回；记录起点和不完整周期会在详情中提示。

首次升级旧账本时，插件先备份原状态，再保存含历史的 schemaVersion=2 数据。软件版本 1.0.0 不代表账本格式降级。

回滚前完全退出宿主，另存当前账本，然后恢复备份插件及与它匹配的状态文件。旧插件可能无法读取新账本，只替换代码不足以完成回滚；保留当前账本可避免丢失升级期间新增记录。

界面读取脱敏快照，不展示 API 密钥；角色不发送模型请求。Live2D Core 首次从官方获取并缓存在用户本机，后续可离线使用；模型和贴图从插件本地加载。

常见问题

安装后没有监控面板

先确认已从菜单和托盘完全退出并重启宿主，再确认实际模型地址为 USTC。若显示连接中或等待识别，须等待读数；提示出现不等于统计已经生效。

请求为什么仍可能断开？

插件仅对 USTC 请求设置 10 分钟流空闲超时，即连续未收到流数据的等待时间，并非任务总时长。该设置不能阻止上游服务器或网络自行断开；停用插件后恢复宿主原行为。

角色无法显示或回退 GIF

检查首次官方 Core 下载是否成功以及环境是否支持 WebGL。角色加载失败不影响监控；系统减少动画设置会停止连续渲染。

如何确认统计正常？

完成一条正常的 USTC 请求，将图表 Token 与宿主用量核对；重启后检查历史是否保留。用量尚未返回或不完整时，不应把未知费用当作零。
